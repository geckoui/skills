# GeckoUI Skills

Skills for building UIs with the GeckoUI component libraries (web + React Native).

## Installation

```
npx skills add geckoui/skills
```

## Versions

The `geckoui` skill on this branch documents **v2**. For **v1**, install from the `v1`
branch, which the installer records in `skills-lock.json` so updates stay on v1:

```
npx skills add https://github.com/geckoui/skills/tree/v1/skills/geckoui
```

## Available Skills

| Skill                                     | For                                      | Description                                             |
| ----------------------------------------- | ---------------------------------------- | ------------------------------------------------------- |
| [geckoui](./skills/geckoui)               | `@geckoui/geckoui` v2 (web)              | Component API, theming, and React Hook Form integration |
| [nativewind](./skills/nativewind)         | `@geckoui/nativewind` (React Native)     | Component API, theming, and override patterns for RN    |
| [nativewind-rhf](./skills/nativewind-rhf) | `@geckoui/nativewind-rhf` (React Native) | React Hook Form wrappers for `@geckoui/nativewind`      |
